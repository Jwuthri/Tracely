# API reference

Everything in `import tracely_sdk as tracely`. The default path is automatic — `init()` plus
`trace()`/`@observe`. Span helpers (the manual escape hatch) are context managers (`with … as span:`);
annotators take a `span`.

## `init(...)`

```python
tracely.init(endpoint="http://localhost:8000", api_key="tracely_dev_key",
             service_name="agent", env="prod", instrument="auto",
             redact=None, tracer_provider=None, export_scopes=None) -> Tracer
```

Configure the OTLP/HTTP exporter pointing at Tracely, register the context-stamping span processor,
and activate auto-instrumentors. Call once at startup; idempotent. If you skip `init`, the first span
call initializes with defaults.

| Argument | Meaning |
|---|---|
| `endpoint` | Your Tracely API origin. Spans go to `{endpoint}/v1/traces`. |
| `api_key` | An ingest key, sent as `Authorization: Bearer …`. |
| `service_name` | `service.name` on the OTel resource. |
| `env` | `prod \| staging \| ci \| dev`, stamped on every span — the gating axis. |
| `instrument` | `"auto"` (probe for **openai / anthropic / google / mistral / langchain** and activate what's installed) · a list like `["openai", "langchain"]` (honored as-is — how you opt into `crewai`, `llama-index`, `litellm`, `bedrock`, `groq` and the agent SDKs) · `False` (export only). |
| `redact` | Scrub payloads before they leave the process — see below. |
| `tracer_provider` | Attach to a provider the host app already owns instead of building one. |
| `export_scopes` | Instrumentation-scope prefixes to export, e.g. `("my_app.agents",)`. |

### `redact` — scrub sensitive content at the exporter

Redaction runs at **export**, the one chokepoint every span passes through, so it covers manual
`set_io` / metadata **and** the zero-touch prompts and completions the auto-instrumentors capture.
Off by default. Set it on the first `init()` call — the exporter is built once.

```python
tracely.init(redact=True)                       # built-in PII patterns
tracely.init(redact=[r"ORD-\d+", r"acct_\w+"])  # your own regexes → [REDACTED]
tracely.init(redact=lambda key, value: value.replace(secret, "***"))   # full control
```

`True` applies the built-in patterns (email, phone, SSN, credit-card-shaped digit runs). A list
replaces every match with `[REDACTED]`. A callable `(attr_key, value) -> value` gets the last word.

### `tracer_provider` / `export_scopes` — living with an existing OTel setup

If something else already called `set_tracer_provider` (a web framework's telemetry, an
OTel-instrumented service), OpenTelemetry ignores a second call — so the default path would silently
export nothing. Hand Tracely the provider instead, and narrow what ships:

```python
tracely.init(
    tracer_provider=existing_provider,
    export_scopes=("my_app.agents", "openinference.instrumentation.langchain"),
)
```

`export_scopes` only matters alongside `tracer_provider`; the SDK's own scope is always included.

## Automatic instrumentation

### `trace(agent=None, *, conversation=None, turn=None, turn_id=None, user=None, trace_name=None, env=None, agents=None, traceparent=None, **metadata)`

A run context — a context manager **or** (sync/async) decorator. Sets `tracely.*` run hints once; a
span processor stamps them onto **every** span started inside (auto-instrumentor spans included), so
the run's identity flows down with no per-span code. Sets context only (opens no span); nested
`trace()`s merge over the enclosing one.

`turn` is the ordinal (`0, 1, 2…`); `turn_id` is your own id for one exchange and — unlike the
`turn()` span helper — lands on **every** span of the turn, which is what the `turn_id` column groups
on. `agents` declares the conversation's agent catalog (see `set_agents` below).

`traceparent` continues a W3C trace context from an incoming request (the `traceparent` header):
your spans join the caller's trace instead of starting a new one. This is how a served agent nests
its internal spans under the turn span Tracely sends when [scenarios](/scenarios) drive it —
`tracely.trace(traceparent=request.headers.get("traceparent"))` is the whole integration. Malformed
values are logged and ignored, never raised.

### `observe(fn=None, *, name=None, as_type="span", capture_input=True, capture_output=True)`

Decorator (`@observe` or `@observe(...)`) that turns any sync/async function into a span:
args → `tracely.input`, return → `tracely.output`, latency, and exceptions → `level=ERROR`, captured
automatically and auto-nested via OTel context. `as_type` (`span | generation | agent | tool | chain
| retriever | thinking | embedding | guardrail | …`) → `tracely.observation.type`.

### `run_in_thread(fn, *args, **kwargs)` → `Thread`

Run `fn` on a new thread that inherits the current span + `trace()` context (auto-nesting is
in-process), so spans it creates nest correctly. Returns the started thread; `join()` it and read
`.result` (or `.exc`).

### `tracely_sdk.<provider>` — non-patching drop-ins

Trace a client **instance** instead of monkey-patching the world. Each module exposes a pre-wrapped
constructor, an async variant where the SDK has one, and a `wrap_*` function for a client you already
built. Nothing global changes, and the spans carry the same attributes as the manual `llm()` helper —
so they inherit `tracely.trace(...)` and map identically.

| Module | Constructors | Wrap an instance | Needs |
|---|---|---|---|
| `tracely_sdk.openai` | `OpenAI`, `AsyncOpenAI` | `wrap_openai(client)` | `openai` |
| `tracely_sdk.anthropic` | `Anthropic`, `AsyncAnthropic` | `wrap_anthropic(client)` | `anthropic` |
| `tracely_sdk.google` | `Client` | `wrap_google(client)` | `google-genai` |
| `tracely_sdk.mistral` | `Mistral` | `wrap_mistral(client)` | `mistralai` |
| `tracely_sdk.openrouter` | `OpenRouter`, `AsyncOpenRouter` | `wrap_openai` | `openai` |
| `tracely_sdk.xai` | `Grok`, `AsyncGrok` (aliases `XAI`, `AsyncXAI`) | `wrap_openai` | `openai` |

```python
from tracely_sdk.openai import OpenAI, wrap_openai, openai

client = OpenAI()                       # pre-wrapped
client = wrap_openai(existing_client)   # wrap one you already have
openai.OpenAI()                         # module proxy — traced constructors
```

`openrouter` and `xai` are OpenAI-wire-compatible presets: same traced OpenAI client, with `base_url`
defaulted to `https://openrouter.ai/api/v1` / `https://api.x.ai/v1`. Pass `api_key=` yourself.

```python
from tracely_sdk.openrouter import OpenRouter
client = OpenRouter(api_key=os.environ["OPENROUTER_API_KEY"])
client.chat.completions.create(model="anthropic/claude-4.6-sonnet", messages=[...])
```

The routed `model` is recorded verbatim (`vendor/model`), so cost attributes to the underlying
provider for free. All six drop-ins capture model · messages · output · usage · tool calls for
non-streaming sync and async calls; for full **streaming** capture use the instrumentor path
(`instrument="auto"`) instead.

## Span context managers

Each opens a span of the given **observation type** and yields the OpenTelemetry `Span`.

### `agent(slug, *, version=None, run_id=None, role=None, conversation=None, turn=None, user=None, trace_name=None, handoff_from=None, edge="delegate")` → `AGENT`

The run root. Sets `tracely.agent.id`/`.version`/`.run_id`/`.role`, `tracely.env`; `conversation` →
`tracely.conversation.id` + `session.id` (threads turns); `turn` → `tracely.turn.index`; `user` →
`tracely.user.id`; `trace_name` → `tracely.trace.name`. `handoff_from` records a delegation edge
(`caller → this agent`, with `edge.type = edge`) — open the sub-agent inside its caller's span.

### `llm(model, *, agent=None, temperature=None, top_p=None, max_tokens=None, frequency_penalty=None, presence_penalty=None, seed=None, tool_calls=None, metadata=None)` → `GENERATION`

A model call. Sets `gen_ai.request.model` + each provided sampling param as `gen_ai.request.*`.
`tool_calls` (a list of names) → `tracely.tool_calls` (tools the model *requested*). `metadata`
(a dict) → `tracely.metadata.*`.

### `tool(name, *, agent=None)` → `TOOL`

A tool / function execution. Sets `gen_ai.operation.name=execute_tool`, `gen_ai.tool.name`.

### `thinking(name="thinking", *, agent=None, model=None)` → `THINKING`

Reasoning as its own span. Optional `model` records which model produced it.

### `retriever(name="retrieve", *, agent=None)` → `RETRIEVER`

A retrieval step. Query in `set_io(input=...)`, hits in `set_io(output=...)`.

### `embedding(model, *, agent=None)` → `EMBEDDING`

An embedding call. Sets `gen_ai.request.model`; record tokens with `set_usage(input_tokens=...)`.

### `guardrail(name="guardrail", *, agent=None)` → `GUARDRAIL`

A safety / policy check. Verdict in `set_io(output={"action": "allow" | "block", ...})`.

### `chain(name, *, agent=None)` → `CHAIN`

A grouping span (a named sub-pipeline, e.g. a RAG pipeline). Nest other spans inside it.

### `turn(turn_id, *, index=None)` · `step(name, *, step_id=None)`

A turn marker (`tracely.turn.id`/`.index`) and a generic step (`tracely.step.name`/`.id`).

## Annotators

| Call | Effect |
|---|---|
| `set_io(span, *, input=None, output=None)` | `tracely.input` / `tracely.output` (objects JSON-encoded). |
| `set_usage(span, *, input_tokens=None, output_tokens=None, thinking_tokens=None, cached_tokens=None, cache_write_tokens=None)` | `gen_ai.usage.*` — `input_tokens` / `output_tokens` / `reasoning_tokens`, plus prompt-cache reads and writes. |
| `set_metadata(span, **kv)` | `tracely.metadata.<key>` — arbitrary tags (scalars kept; others JSON-encoded). |
| `set_agents(span, agents)` | `tracely.agents` — the conversation's agent catalog (below). |
| `set_state(delta, span=None, *, max_bytes=4096)` | `tracely.state.<channel>` — the state channels this step wrote (below). |
| `error(span, message="")` | Marks the span `StatusCode.ERROR` → `level=ERROR`. The failure signal. |
| `flush()` | Force-flush the OTLP exporter — call before the process exits. |

### `set_agents(span, agents)` — the agent catalog

Declare which agents and tools *exist* in this conversation, not just which ones fired. It powers the
Conversation Agents panel and is addressable from evaluator prompts as `@LIST_AGENT`.

`name`, `description` and `tools` are interpreted; **every other key rides along verbatim** and
renders as an expandable row in the panel — `system_prompt`, `model`, `guardrails`, `config`,
whatever describes your setup. Declaring is the only way Tracely can know things tracing can't see
(a guardrail that never fired, the prompt of an agent that wasn't invoked this turn).

```python
agents = [
    {
        "name": "billing",
        "description": "refunds and charges",
        "system_prompt": "You are the billing specialist…",   # free-form — kept verbatim
        "model": "gpt-5.2",
        "tools": {
            "get_charges": {"name": "get_charges", "description": "list charges",
                            "parameters": {"type": "object", "properties": {"user_id": {"type": "string"}}}},
        },
    },
]

with tracely.trace(agent="router", conversation="c1", agents=agents):   # flows onto every span
    ...
```

Prefer the `trace(agents=…)` form, which stamps it across the run. `set_agents(span, …)` is for
pinning the catalog to one specific span (usually the root). `tools` may also be a plain list of
`{name, description, parameters}` objects.

Not on Python, or want to declare without touching instrumentation? The same catalog can be pushed
per conversation over HTTP:

```bash
curl -X POST "$TRACELY_API/api/sessions/<conversation-id>/config" \
  -H "Authorization: Bearer $TRACELY_KEY" -H "content-type: application/json" \
  -d '{"agents": [{"name": "billing", "description": "refunds and charges"}]}'
```

Without any declaration the panel still works — Tracely derives an **observed** view from the spans
themselves (which agents ran, which tools executed, the system prompt found in the messages). A
declared catalog wins outright when present.

### `set_state(delta, span=None, *, max_bytes=4096)` — shared state

Record the state channels a step **wrote** — a LangGraph-style state delta, a scratchpad update, a
memory write. Each key becomes its own `tracely.state.<channel>` attribute on the current span (or
`span` if given); values are JSON-encoded and truncated at `max_bytes` per channel. The UI folds the
deltas in span order into the **Conversation State** panel and the per-message **State Δ** column.

```python
@tracely.observe(as_type="tool")
def add_to_cart(item: str):
    cart.append(item)
    tracely.set_state({"cart": cart, "last_action": "add_to_cart"})   # what this step changed
```

Record the **delta**, never a full snapshot — Tracely tracks add/update/unchanged per channel by
comparing consecutive writes. **LangGraph needs no code at all:** a node's return value *is* its
channel update, and ingest marks those spans (`tracely.state_source=output`) so the UI reads them as
deltas automatically. `set_state` outside any recording span warns and drops (call it inside an
`@observe`d function or an open span helper).

## Hermetic replay

`call_tool(name, fn, *, args=None, agent=None)`, `call_llm(model, fn, *, input=None, usage=None,
agent=None)`, `with fixtures(bundle): …`, `fixture(kind, name)`, and the `ToolError` exception — see

## What Tracely reads

Beyond standard `gen_ai.*` / OpenInference attributes, these `tracely.*` hints become **indexed
columns** on the span row:

`tracely.agent.id` · `.version` · `.run_id` · `.role` · `tracely.user.id` · `tracely.trace.name` ·
`tracely.conversation.id` (also read from `session.id`) · `tracely.turn.id` / `.index` ·
`tracely.step.id` / `.name` · `tracely.observation.type` · `tracely.tool_calls` ·
`tracely.handoff.caller_agent_id` / `.callee_agent_id` · `tracely.edge.type` · the
`gen_ai.request.*` sampling params · `gen_ai.usage.*` token counts · `gen_ai.tool.name` /
`gen_ai.operation.name` · `tracely.env`.

Carried through as span metadata (not columns) and read by specific features:
`tracely.agents` (the declared agent catalog — stripped into the registry at ingest) ·
`tracely.state.<channel>` (the state panel) · `tracely.metadata.<key>` (your tags) ·
`tracely.replay.fixture` (marks a hermetic-replay span as served-from-fixture).

If you emit **raw OTLP from another language**, these are the attribute names to set — POST
protobuf-JSON to `{endpoint}/v1/traces` with `Authorization: Bearer <ingest key>`. (In OTLP/JSON,
`traceId`/`spanId` are **base64**, per protobuf's canonical JSON mapping — hex ids decode to
garbage without erroring. Any real OTel exporter handles this for you.)

Beyond `tracely.*`, these third-party conventions are read natively, so most tracers need no
Tracely-specific attributes at all: **OpenInference** (`openinference.span.kind`, `llm.*`), **OTel
GenAI semconv** (`gen_ai.*`, including the span-event message form), **OpenLLMetry/Traceloop**
(`gen_ai.prompt.<i>.*`, `traceloop.span.kind`, `traceloop.entity.*`), **Vercel AI SDK** (`ai.*`),
and **LiteLLM** (`llm.openai.*`). Failure is read from an ERROR span status, a recorded
`exception` event, or `error.type`.

Agent slug + version are auto-registered into the Postgres registry on ingest. Input/output are
stored in dedicated columns (and shown in Input/Output tabs), so they're **excluded** from the
attributes list to avoid duplication.
